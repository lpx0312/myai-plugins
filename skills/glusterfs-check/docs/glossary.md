# 术语表

本技能的"语言"。改 `SKILL.md` / `checks.md` 时若引入新词，先加到这里。

## 模式与授权

| 术语 | 含义 |
|---|---|
| **巡检（snapshot）** | 单次只读采样。**不构成趋势结论**：heal 条目、容量变化需多次比对才有意义 |
| **runbook 模式** | 只输出命令清单 + 回填表，**一条连接都不建**。用户在说"只给命令/别连"、或没点名目标时进入 |
| **全量直连** | 目标、范围都明确，L1+L2（+L3 有 kubeconfig 时）全查 |
| **聚焦直连** | 只查用户点名的那几项（如只看某个卷），其余标 `SKIP(out-of-scope)` |
| **授权闸门** | 连目标前的判定。硬闸只有两条：目标明确 + 范围只读（ADR-0001） |

## 分层

| 术语 | 含义 |
|---|---|
| **L1** | gluster 层：glusterd、peer、卷、brick、heal、容量 |
| **L2** | heketi 层：服务、拓扑、设备、卷对账 |
| **L3** | Kubernetes 层：SC、Secret、PVC/PV、事件 |
| **执行域** | 某检查项该在哪台机器跑：`gls`（任一节点）/ `each-gls`（每台砖主机）/ `heketi` / `k8s` |

## 判定

| 术语 | 含义 |
|---|---|
| **P0** | 数据风险或存储已不可用，当天处理 |
| **P1** | 冗余降级或即将不可用，24h 内处理 |
| **P2** | 趋势性 / 配置偏差，计划内处理 |
| **INFO** | 事实为真但无需处置，**不计入 P0/P1/P2 计数**（ADR-0004） |
| **SKIP(原因)** | 无法判定：无权限、无 kubeconfig、超时、版本字段缺失等 |
| **首见 / 复查** | 同一指标第一次采样 / ≥10 分钟后的第二次采样；heal 条目只有复查才能定性 |
| **单一根因原则** | 同一根因只记一次，取最严重那级（如 brick 离线只记 L1-05 的 P0，L1-07 不再记 P1） |

## 存储对象

| 术语 | 含义 |
|---|---|
| **brick** | 卷在单节点上的数据目录，通常 `<vg>/brick_<brickId>/brick`，其上是独立 xfs LV |
| **thin pool** | LVM 精简池，一条 brick 一个池。`tp_` 前缀只是名字，**与 `brick_` 后缀不保证一致**，映射一律读 `lvs -o pool_lv` |
| **data_percent** | 池的**块分配率**，不是文件系统使用率。池高 + `df` 低 = 陈旧分配（删了没回收），处置是 `fstrim`（人工） |
| **metadata_percent** | 池元数据占用率，满了同样锁死池 |
| **heal entries** | 待自愈条目数。`0` 是健康；瞬时非 0 在繁忙业务下属正常，需复查 |
| **split-brain** | 副本冲突，需人工介入，`>0` 即 P0 |
| **arbiter 卷** | `replica=2 + arbiter=1`，第三份只存元数据；容量口径与 replica-3 **不同**，不要套用 |
| **Distribute 卷** | `replica=1, arbiter=0`，无冗余、**不产生 heal**，heal 检查必须跳过 |

## 工程约定

| 术语 | 含义 |
|---|---|
| **命令白名单** | `references/commands.md`。白名单外一律不执行；脚本服从白名单，不为脚本扩白名单（ADR-0003） |
| **三态输出** | 脚本每段以 `##STATE <ID> OK\|ERR\|SKIP` 结尾；`ERR`/`SKIP` 必须落成 `SKIP(...)`，不得判 PASS（ADR-0002） |
| **越界命令** | 本次执行了但不在白名单里的命令。出现即须在报告自检里单列 |
| **脱敏** | 凭据进变量、不进输出；打印命令时 secret 显示 `***` |
| **人读版脚本** | `scripts/gluster-health.py`。输出中文结论表给人看，不产 `##STATE`，不替代契约脚本；判定阈值与 `thresholds.md` 同源（ADR-0012） |
| **`##F` 标记** | findmnt 逐砖结果的行走标记，形如 `##F <砖目录>`。解析按目录名匹配、**不按行序**，防 ssh 警告等噪声把行顶错位（ADR-0012） |
| **golden sample** | 脚本输出的基准样例，用于改脚本时回归。**当前尚未建立**（待补） |
