# ADR-0006 技能目录卫生

- 状态：已采纳（2026-10-21）
- 决策：用户（lipanx）
- 影响文件：`references/remediation/`

## 背景

`references/remediation/` 里混进了一个 69 KB 的现场日志 `afc-bairong-bc5c5b846-8sl9b.log`。
它不是手册、不是脚本，和"只读巡检"无关；现场日志往往含客户标识、IP、业务名，属于敏感数据，
不应该进技能目录（更不应该随技能分发）。

## 决策

技能目录只允许四类内容：

| 位置 | 允许内容 |
|---|---|
| `SKILL.md` | 技能入口 |
| `references/*.md` | 检查项、阈值、白名单、拒绝话术 |
| `references/remediation/*.md` | 人工修复手册 |
| `scripts/*.sh` | 只读采集脚本 |
| `docs/`（ADR、术语表） | 关于技能本身的决策记录 |

现场日志、dump、临时分析产物**移出**技能目录，单独存放。

## 后果

- `afc-bairong-bc5c5b846-8sl9b.log` 已移动到 `.agents/_artifacts/glusterfs-check/`。
- 后续若要把现场日志作为"已知案例"引用，只在手册里写**脱敏摘要 + 存放位置**，不复制原文。
