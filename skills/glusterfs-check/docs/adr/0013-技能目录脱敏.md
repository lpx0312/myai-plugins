# ADR-0013 技能目录脱敏

- 状态：已采纳（2026-10-24）
- 决策：用户（lipanx）
- 影响文件：`SKILL.md`、`scripts/gluster-health.py`、`tests/`（fixtures 文件名与内容）、`tests/test-report.py`

## 背景

本技能归档在公开仓库（myai-plugins）。初版提交里携带了真实环境的内网拓扑：
真实内网 IP 段出现在 SKILL.md 示例、`gluster-health.py` 的默认 `--nodes`、
fixtures 文件名与内容里；fixtures 还带真实卷 ID、集群 ID、VG/brick 32 位 ID、
真实主机名。（具体值此处也不再复述，见 git 历史。）
这违反"内网信息不进公开仓库"的全局约定——等于对外暴露"哪些内网机器跑着 glusterfs+heketi"。

## 决策

1. **示例一律用占位网段** `10.10.0.11-13`（RFC1918 但非本环境实际网段）。
2. **fixtures 全量换 ID**：32 位 hex → `f000…000N` 序号（全局一致映射，跨文件可对账），
   uuid → 全零形态，IP/主机名同步替换；文件名与内容一起改。
3. `gluster-health.py` 的默认节点串仍是占位 IP —— **默认值只为可读性**，
   真实巡检必须显式 `--nodes`（授权闸门本来就要求用户点名主机）。
4. 回归断言随 ID 同步更新；`tests/README.md` 已声明 fixtures 是"真实采集结果的脱敏副本"。

## 后果

- 公开仓库不再含真实拓扑；误报回归（`##F` 标记、`Warning: Permanently added` 噪音行）
  仍由脱敏样本覆盖。
- 历史提交里的真实 IP 已随 git 历史存在，**本轮不重写历史**（用户自知；如需彻底清除
  需 filter-repo + force push，另行决策）。
- 新增 fixture 时照此规则：先脱敏再入库。
