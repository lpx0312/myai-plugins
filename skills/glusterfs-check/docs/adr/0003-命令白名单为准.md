# ADR-0003 命令白名单为准

- 状态：已采纳（2026-10-21）
- 决策：用户（lipanx）
- 影响文件：`scripts/k8s-check.sh`、`references/commands.md`

## 背景

`references/commands.md` 是对用户的**只读承诺**：白名单外一律不执行。但 `k8s-check.sh` 实际用了
`kubectl get sc -o yaml` 和 `-o custom-columns`，白名单里只有 `-o json`。也就是说，跑自带的 L3 脚本
必然产生"越界命令"，§7 自检形同虚设。

## 决策

**白名单是权威，脚本服从白名单**，不为脚本方便去扩白名单。

- kubectl 一律 `-o json`；
- 需要列式视图时由分析阶段在本地对 JSON 做投影，而不是让 kubectl 输出表格。

## 后果

- `-o json` 体积可能很大 → 脚本在每个 JSON 块后附 `##SIZE <ID> bytes=N`；
  报告按 `SKILL.md` §4.4 截断并注明"已截断，完整输出需授权落盘"。
- `K8S-02`（Secret 类型）依赖 SC 里的 `secretName` / `secretNamespace`，脚本无法自解析，
  由分析阶段解析 K8S-01 输出后单独执行（命令本身仍在白名单内）。
